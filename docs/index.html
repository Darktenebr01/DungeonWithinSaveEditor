◆ Dungeon Within Save Editor

Dungeon Within Save Editor Open-source save editor for Dungeon Within on Android — emulator or rooted phone, plus live Dark Lord stats and map jumps.

Change gold and resources, monster levels, stats and abilities, facility modifiers, Dark Lord aspects and variants, then encrypt the save back with the game's own code so it loads like a normal save. No AES key is shipped, no offsets are hardcoded, and every edit is checksum-validated.

Live tools (v1.4.7)

The ACTIVE GAME group drives the running game instead of the save file:

  • Live Dark Lord — polls save.es3 from the device every 3 seconds and decrypts it locally; the editor buffer is only replaced while it matches the last snapshot.
  • Start live stats — Frida hook that overrides UnitTable base stats for Dark Lord tables (HP, STR, DEX, CON, INT, WIS, CHA). Units and runs created after it starts use the new values; the save is untouched.
  • Start map hook — forces every rendered run-map node to stay clickable and bypasses the adjacency check.
  • Jump to turn — writes StageData.dayNodeCursor on Unity's main thread when the map loads, jumping to a chosen turn (1–16; 15 lands on the boss in testing).

Everything is process-local: stopping a hook or restarting the game restores the normal rules.

How it works

Dungeon Within stores its save as an ES3E container encrypted by the game's own code. The editor does not re-implement that crypto. It attaches with Frida, hooks ES3Saver.DecryptAndDecompress to capture the plain JSON, edits that text while keeping the ES3 dialect intact, then fills the game's decrypted buffer with your JSON and calls the real CompressAndEncrypt on the game's thread. The two functions are found by name at runtime and cached per game version and ABI, so there are no hardcoded offsets.

FAQ

Is there a Dungeon Within save editor for Android?

Yes. This editor runs on Windows and edits the Android save through adb and Frida; it works with emulators (MuMu, LDPlayer, BlueStacks) and rooted phones, on any ABI.

How do I edit my Dungeon Within save?

Start the game once so the save exists, connect the device, press Find save to decrypt, change what you want, then Apply to file and Encrypt save. The encrypted result is verified by decrypting it again, and the previous save is restored if verification fails.

Do I need the encryption key?

No. The game itself decrypts and encrypts the file; the editor only drives it.

Will it work after a game update?

Usually yes. The two crypto functions are located by name and the offsets are cached per version:abi; a new build only needs one calibration run.

Can I edit the Dark Lord's live stats?

Yes. Live Dark Lord → Start live stats hooks the game and overrides the base stats of the Dark Lord tables for units and runs created after the hook starts. It never writes the save.

Can I skip the run map or jump to the boss?

Yes. Start map hook makes every rendered node selectable, and Jump to turn sets the run's day cursor when the map reloads (15 lands on the boss/end zone). Skipped days do not grant their rewards.

Is it safe for my save?

It keeps backups, verifies the encrypted output against a marker value and rolls back on mismatch. Keep your own copy anyway, and use it on single-player saves only.

Requirements

  • Windows 10/11 (the CLI also runs anywhere Python does)
  • Windows 10/11 x64 — the release is zero-install (bundles adb and frida-server)
  • A rooted device or emulator (root is required by Android for the save and frida-server)
  • Nothing else: Prepare device pushes and starts frida-server automatically
